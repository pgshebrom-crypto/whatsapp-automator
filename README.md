# 🚀 WhatsApp Automator PRO

Uma ferramenta web moderna, rápida e segura para automação de mensagens personalizadas no WhatsApp através de planilhas. Este projeto foi desenvolvido para facilitar o envio de mensagens individuais sem o risco de banimentos por disparos em massa automatizados.

## ✨ Funcionalidades

- **📁 Leitura de Planilhas:** Suporte completo para arquivos `.xlsx`, `.xls` e `.csv`.
- **🔗 Mapeamento Flexível:** Seleção manual de colunas para Nome e Telefone.
- **🏷️ Variáveis Dinâmicas Ilimitadas:** Use `{nome_da_coluna}` para injetar dados da planilha diretamente na mensagem.
- **👁️ Live Preview:** Veja exatamente como a mensagem ficará antes de enviar.
- **📊 Barra de Progresso:** Acompanhe em tempo real o status dos seus envios.
- **🔍 Busca e Filtro:** Localize contatos rapidamente em listas grandes.
- **🌙 Design Premium:** Interface elegante com Tema Escuro (Dark Mode).
- **💾 Persistência de Dados:** O progresso do envio é salvo automaticamente no seu navegador.
- **✍️ Editor Formatado:** Botões para Negrito, Itálico e Riscado.

## 🛠️ Tecnologias Utilizadas

- **React + TypeScript**
- **Vite** (Build tool ultra-rápida)
- **SheetJS (xlsx)** (Processamento de planilhas no cliente)
- **Lucide React** (Ícones modernos)
- **Vanilla CSS Premium** (Design customizado e performático)

## 🚀 Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/pgshebrom-crypto/whatsapp-automator.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

## 🔐 Segurança e Privacidade

Este projeto é **100% Client-Side**. Isso significa que nenhum dato da sua planilha é enviado para servidores externos ou bancos de dados. Todo o processamento ocorre localmente no seu navegador, garantindo a privacidade total dos seus contatos.
